# E1 - Historical knowledge

**Question:** Does historical attack knowledge improve next-step prediction?

Sample: 24 synthetic incidents from 4 attack templates (6 each), one dataset, one seed. No confidence intervals are given because the incidents are not independent draws; treat differences of a few points as noise.

**Metrics:** top1: the true next technique is the first prediction (ties broken by technique id). top1_tie: the same, but a target tied for first with m - 1 others counts 1/m, which removes alphabetical luck. top3: the target is among the first three. mrr: mean of 1/rank over the model's full ranking, 0 if the target is not ranked (the API exposes only the top 5). precision / recall / f1: macro-averaged over the techniques that occur as targets, using the top prediction only. An instance is one prefix of one incident's trajectory; an incident with L steps gives L - 1 instances.

## What the numbers show

- With a history that contains the attack's reference sequence, top-1 is 0.722 (65 of 90). Comparators: 0.005 for no knowledge at all, and 0.156 (14 of 90) for always naming the most frequent next step seen in other incidents. This is the best case for history: three of the 11 hand-written sequences are the generator's own templates.
- With the tested pattern's reference removed (an attack the history has not seen), top-1 is 0.278 (25 of 90). By pattern: A 0/18, B 11/24, C 0/24, D 14/24. The gain is confined to patterns B and D and comes from distractor sequences, written by the same author, that share parts of their paths; patterns A and C get nothing.
- With those overlapping distractors removed as well, top-1 is 0.133 (12 of 90; by pattern: A 0/18, B 11/24, C 1/24, D 0/24). So this experiment does NOT show that history helps on unseen attacks.
- Real MITRE ATT&CK group data does not help: 0 of 90 correct alone, and pooling it with the hand-written sequences lowers top-1 from 0.722 to 0.311.
- Unseen pattern with other families' incidents available: 7 of 90 without history, 28 of 90 with it; the same B-and-D caveat applies.
- Known pattern with sibling incidents available: 73 of 90 without history, 73 of 90 with it. History adds nothing once the same pattern has been seen locally.
- Pattern D (no reference in the history): 14 of 24 correct, but 0 of 24 once the distractor sequences that share a 2-step path with D are removed.
- Strict end-to-end with the label-free pipeline and the default history: 33 of 90 true transitions predicted (top-1 0.367); the pipeline reproduced the true path so far for 47 of them.

## Caveats

- What E1 supports: a Markov model over the hand-written sequences predicts well when the history contains the attack's own template; MITRE group data adds nothing with this method; history adds nothing once sibling incidents exist. What it does not support: that history helps on unseen attacks, or that independently sourced threat intelligence would help.
- All hand-written sequences, including the distractors, were written by the author of the data generator.
- Patterns A and C are held out together: A's reference is a prefix of C's.
- 'none' with no in-environment incidents is an analytic chance level over 222 techniques, not a run; it is a very weak comparator, which is why the frequency baseline is quoted beside it.
- The end-to-end table has only history-trained rows, because rows that train on other incidents would use their labelled trajectories. A true transition counts as correct only if the pipeline reproduced the true path up to that point and the top prediction is the true next technique.
