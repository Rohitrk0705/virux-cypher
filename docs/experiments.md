# The 3 Locked Experiments

E1 - Historical knowledge:  prediction WITHOUT historical KG  vs  WITH historical KG
     Q: does historical attack knowledge improve prediction?

E2 - Temporal information:  static KG  vs  temporal (ordered) KG
     Q: does temporal ordering improve matching/prediction?

E3 - Similarity discrimination:  known attack / modified variant / novel attack
     Q: can the system tell known vs variant vs previously-unseen?

Metrics: Precision, Recall, F1, Top-1, Top-3, MRR, similarity accuracy, FPR.
